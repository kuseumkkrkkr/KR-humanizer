# 제품 설명문 윤문 기록

## 적용 조건

- 엔진: Codex EXEC
- 모드: `balanced`
- 높임 단계: `50` (원문의 설명체 유지)
- 보호 대상: `KR-humanizer`, `Codex`, `Claude Code`, `npm CLI`, `로컬 GUI`, 기능 및 실행 방식

## 사전 진단

- 문단: 1개
- 문장: 4개
- 평균 문장 길이: 65자
- 확정 가능한 지적: 마지막 문장 87자로 장문 후보
- 오탈자·비가시 문자: 발견되지 않음

## 수락한 변경

1. `읽을 수 있도록` → `읽도록`
2. `국립국어원 근거` → `국립국어원의 근거 자료`
3. `별도 모델 API` → `별도의 모델 API`
4. `각 도구용 플러그인` → `각 도구에 맞는 플러그인`

문장 순서와 제품 주장은 바꾸지 않았습니다. 작성 이력 문구는 사용자의 요청에 따라 윤문 결과 뒤에 추가했습니다.
