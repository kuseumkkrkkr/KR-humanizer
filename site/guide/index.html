INSTALLATION GUIDE

글 한 편으로
시작하기.

Node.js 20 이상과 로그인된 Codex CLI 또는 Claude Code CLI가 필요합니다. 별도 모델 API 키를 입력하지 않습니다.

npm CLI

설치

npm install -g github:kuseumkkrkkr/KR-humanizer

Plan 그래프

kr-humanizer plan brief.txt --explanation balanced --out graph.json

그래프 초안

kr-humanizer draft brief.txt --graph graph.json --out draft.json

윤문 제안

kr-humanizer rewrite draft.txt --graph graph.json --explanation minimal --out proposal.json

제외한 노드는 모델 입력에서 빠집니다. 윤문 제안도 원문을 덮어쓰지 않으며 문장별 Diff에서 수락한 변경만 적용합니다.

로컬 GUI

kr-humanizer gui

브라우저에서 127.0.0.1 전용 검토 화면이 열립니다. 프롬프트가 있으면 Plan 모드로 노드를 먼저 만들고, 노드의 내용·순서·포함 여부와 설명률을 정한 뒤 초안과 윤문을 실행할 수 있습니다.

입력은 KR-humanizer 서버가 별도 원격 저장소로 전송하지 않습니다. 모델 작업을 요청할 때만 선택한 Codex 또는 Claude Code CLI 프로세스가 실행됩니다.

Codex 플러그인

codex plugin marketplace add kuseumkkrkkr/KR-humanizer codex plugin add kr-humanizer@kr-humanizer

새 스레드에서 글쓰기를 요청하면 공용 Skill이 Plan 노드 → 그래프 편집 → 초안·진단 → Diff 확인 순서를 안내합니다. 기존 글은 진단부터 시작할 수 있습니다.

Claude Code 플러그인

claude plugin marketplace add kuseumkkrkkr/KR-humanizer claude plugin install kr-humanizer@kr-humanizer

CLI에서 --engine claude를 선택하면 plan 권한과 비영속 세션으로 Claude Code를 실행합니다.

윤문 방식

  • fluent최소한의 문법·자연스러움 수정
  • balanced명료성·흐름·문장 길이 균형 편집
  • strict문체 혼용·반복·모호성까지 엄격 검토
  • concise주장과 조건을 보존한 간결화

높임 정도는 0~100의 5단계, 설명률은 최저·중간·최대 중에서 선택합니다. 최대도 제공되지 않은 사실을 추가하지 않습니다.
