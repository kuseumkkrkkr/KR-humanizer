OBSIDIAN KNOWLEDGE VAULT

감이 아니라
근거를 찾습니다.

“자연스럽게 고쳐 줘”라는 한 줄에 모든 판단을 맡기지 않습니다. 입력 문장에 해당하는 한국어 규범과 편집 원칙만 골라 윤문 프롬프트에 제공합니다.

무엇이 들어 있나

  • 띄어쓰기조사·의존 명사, 보조 용언
  • 문장 부호종결 부호, 쉼표와 접속 부사
  • 문법·문체상대 높임, 종결 어미, 문장 성분 호응
  • 공공언어명료성, 행위 주체와 책임 관계

현재 기본 저장소에는 국립국어원 자료를 재구성한 카드 9개와 공개 한국어 윤문 Skill의 작업 방식을 추상화한 카드 5개가 있습니다.

카드 구조

--- id: nikl-spacing-particle-dependent-noun kind: norm authority: 국립국어원 source_url: https://www.korean.go.kr/... source_section: 한글 맞춤법 제41항·제42항 tags: [어문규범, 띄어쓰기] retrieval_terms: [할수, 할 수, 의존 명사] --- ## 프롬프트 지침 조사는 앞말에 붙이고 의존 명사는 띄어 쓴다.

출처·적용 구간·태그·검색어가 없는 노트는 검색에서 제외합니다. 원문 전체나 외부 Skill 프롬프트를 복제하지 않습니다.

검색 과정

  1. 입력 글에서 한국어·영문 토큰과 정확 구문을 찾습니다.
  2. 윤문 방식과 높임 단계는 관련 카드의 순위를 미세 조정합니다.
  3. 제목·태그·검색어·지침을 점수화해 최대 6개를 선택합니다.
  4. 출처와 함께 6,000자 이내의 참고 구획으로 프롬프트에 넣습니다.
  5. 국립국어원 규범과 공개 Skill 관찰이 충돌하면 규범을 우선합니다.

검색 결과는 모델에 제공된 후보입니다. 특정 변경에 실제 적용됐다는 증명이나 국립국어원의 공식 판정 결과가 아닙니다.

내 Vault 사용

kr-humanizer knowledge draft.txt --vault D:\my-writing-vault kr-humanizer rewrite draft.txt --engine codex --vault D:\my-writing-vault

사용자 Vault는 명시적으로 신뢰한 로컬 입력으로 처리됩니다. 출처가 불분명한 공유 폴더나 외부에서 자동 동기화된 노트를 바로 연결하지 마세요.

기준 자료

국립국어원 한국어 어문 규범, 상대 높임 온라인가나다, 공공언어 지침과 글쓰기 첨삭 말뭉치 연구를 사용했습니다. 각 카드에는 원문 위치를 다시 확인할 수 있는 URL과 절 이름이 있습니다.
