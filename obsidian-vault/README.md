# KR-humanizer 윤문 지식 저장소

이 폴더를 Obsidian에서 `Open folder as vault`로 열 수 있습니다. 모든 지식 카드는 Markdown과 YAML frontmatter로 구성되며, KR-humanizer는 같은 파일을 로컬에서 직접 검색합니다.

- `00-윤문-지식-지도.md`: 전체 색인
- `규범/`: 국립국어원 규범·해설·글쓰기 자료를 적용 단위로 재서술한 카드
- `skills/`: 공개 한국어 윤문 Skill의 구조와 검토 축을 기록한 카드
- `templates/`: 새 카드 작성 형식

원문 전체를 복제하지 않습니다. 각 카드의 `source_url`과 `source_section`에서 원문을 확인하고, `프롬프트 지침`에는 윤문 시 사용할 짧은 적용 규칙만 둡니다.

현재 검색 가능한 카드는 25개입니다. 국립국어원 근거 카드 20개와 공개 Skill의 작업 방식만 추상화한 관찰 카드 5개를 분리하며, 둘이 충돌하면 국립국어원 근거를 우선합니다.

정통 규범 카드는 `적용 조건`과 `예외와 경계`를 함께 적습니다. `trigger_terms`는 실제 오표기나 특징적인 구문이 입력에 있을 때 검색 순위를 올리는 용도이며, 자동 수정의 근거로 단독 사용하지 않습니다.
