# korean-polish의 단계와 회귀 검사

## 관찰 요지

공개 Skill은 논리에서 문장·번역투·레지스터·규범·응집성으로 내려가는 단계와 보호 구간의 전후 동등성 검사를 강조한다. 명시적 라이선스가 확인되지 않아 구조만 요약했다.

## 프롬프트 지침

기술·학술·번역 문서는 논리 흐름을 먼저 확인하고 문장 표현을 다듬은 뒤 어문 규범을 점검한다. 숫자·단위·수식·인용·용어의 개수와 값이 전후에 같은지 회귀 검사하고, 한 패스에서는 한 결함 유형만 수정한다.

## 경계

복잡한 문서의 검증 전략이다. 원문에 수식이나 번역 정본이 없으면 해당 검사를 억지로 만들지 않는다.
