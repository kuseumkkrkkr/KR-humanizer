# 제품 기획 초안

## 목표

- 글쓴이의 의미·사실·말투를 보존하면서 읽기 부담을 줄인다.
- 자동 덮어쓰기 대신 `진단 → 제안 → 비교 → 선택 수락 → 저장` 순서를 지킨다.
- 별도 LLM API 키 없이 로그인된 Codex/Claude Code CLI를 실행한다.

## 사용자 흐름

1. 원문 붙여넣기 또는 파일 열기
2. 문단, 긴 문장, 중복 표현, 기본 오탈자, 비가시 문자 확인
3. 윤문 강도와 실행 엔진 선택
4. 문장별 전후와 단어 차이 확인
5. `어순 변경` 표식과 의미 흐름 그래프 확인
6. 각 변경을 선택 수락하고 결과 복사/저장
7. 수락·거절 성향을 로컬 메모리 또는 localhost mem0에 기록

## 산출물 구조

- npm CLI: 분석, 정리, 윤문 실행, GUI 시작
- 공용 플러그인: Codex/Claude가 동일한 검토 절차와 CLI를 사용
- GUI: 플러그인에서 CLI 명령으로 열 수 있는 localhost 웹 앱

## 기술 경계

- 플러그인 자체 패널 UI는 호스트별 지원과 배포 제약이 달라 MVP 범위에서 제외한다.
- 데스크톱 설치 앱은 로컬 GUI 사용성 검증 후 Tauri 래퍼로 분리할 수 있다.
- 완전한 맞춤법 판정은 사전·형태소 분석기 없이 보장하지 않는다. 현재 규칙은 설명 가능한 고신뢰 항목만 포함한다.
- “AI 워터마크” 판별/제거를 주장하지 않는다. 탐지 가능한 Unicode·제어문자만 사용자 확인 후 정리한다.
- mem0 기본 구성은 외부 모델을 사용할 수 있어 자동 활성화하지 않는다. localhost self-hosted 인스턴스만 허용한다.

## 수용 기준

- 분석과 sanitize가 네트워크 없이 동작한다.
- Codex 어댑터는 read-only/ephemeral 모드와 JSON Schema를 사용한다.
- 모든 변경은 원문/수정문과 유형을 함께 보여 준다.
- GUI는 원문을 자동으로 덮어쓰지 않는다.
- Windows/macOS/Linux에서 npm 패키지 설치가 가능하다.

## 반복 CV

- 정치·경제·사회 최소 프롬프트를 각각 독립 세션에서 생성한다.
- 같은 원문/윤문 pair는 같은 fold에 넣어 누수를 막는다.
- 규칙 기반 지표와 블라인드 모델 평가를 분리한다.
- 합성 결과는 실제 독자 선호나 AI 판별 회피 성능으로 표현하지 않는다.
