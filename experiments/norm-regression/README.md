# 정통 국어 규범 회귀 평가

- 입력: `2026-09-05-input.txt`
- 목적: 국립국어원 근거 카드의 검색과 실제 EXEC 윤문 반영 확인
- 확인 항목: `몇일→며칠`, `금새→금세`(시간 의미), `예상됬습니다→예상됐습니다`, `안됌→안 됨`, `웬지→왠지`, `어떡해 신청→어떻게 신청`, 병렬 구조, 긴 안내 문장 분할
- 경계: 문맥 의존 표현은 정규식 자동 적용이 아니라 EXEC 제안과 Diff에서 확인
- 1차 실행 관찰: 핵심 8항목은 교정됐으나 `목적은 … 데 있어요`가 새로 생겨 번역투 경계 카드를 추가하고 재실행함
