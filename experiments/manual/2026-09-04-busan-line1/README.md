# 부산 도시철도 1호선 단일 윤문 실험

- 원문 생성 지시: `부산 도시철도 1호선에 대한 글을 작성하세요.`
- 추가 문체·길이·구성 지시: 없음
- 윤문: KR-humanizer `balanced`, 높임 50(원문 유지), Codex CLI
- `01-no-prompt.md`: 최소 지시 생성 원문
- `02-analysis.json`: 사전 진단
- `03-knowledge.json`: Obsidian Vault 검색 후보
- `04-proposal.json`: 첫 번째 윤문 실행의 문장별 변경 제안
- `05-humanized.md`: 링크 분할 문제를 피하기 위해 다시 실행해 받은 전체 윤문 본문
- `06-humanized-analysis.json`: 윤문본 재진단
- `07-verification.json`: 수치·URL 보존과 사실 확인 기록

## 실행 중 확인한 제한

문장별 수락기는 Markdown 링크 URL의 `?`를 문장 경계로 잘못 인식했다. 따라서 `04-proposal.json`의 모든 변경을 일괄 적용한 중간 결과는 사용하지 않았으며, 링크와 문단이 온전한 엔진의 `rewrittenText`를 `05-humanized.md`에 저장했다. 원문은 덮어쓰지 않았다.

`04-proposal.json`과 `05-humanized.md`는 서로 다른 두 번의 윤문 실행 결과이므로 문구가 완전히 같지는 않다.

## 사실 확인 경계

윤문기는 사실 검증기가 아니므로 원문의 오류도 의미 보존 대상으로 남긴다. 원문과 윤문본의 “1985년 노포–범내골 구간이 처음 개통”이라는 서술은 부산교통공사 기록과 다르다. 공식 기록에는 1985년 7월 19일 첫 개통 구간이 `범내골~범어사 16.1km`로 적혀 있다. 실험 결과에는 모델의 원문과 윤문 동작을 그대로 남기고, 오류를 여기에서 별도로 표시했다.
